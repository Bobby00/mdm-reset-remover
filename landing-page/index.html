How It Works

Follow these steps to remove the MDM reset message.

1

Enable ADB Debugging

Go to Settings > About Phone > tap Build Number 7 times to unlock Developer Options. Then enable USB Debugging.

2

Set Device Owner

Connect your phone to a computer via USB and run:

adb shell dpm set-device-owner com.mdmresetremover.app/.DeviceAdminReceiver

Requires a factory-reset device or no existing device owner.

3

Run the App

Install MDM Reset Remover, grant all permissions, and tap "Run All Steps" to clear Play Services data, disable Play Store, and install Aurora Store.

ADB & Device Owner Setup

Why these steps are necessary.

Why Device Owner is required

On modern Android, a normal app cannot disable system apps like the Play Store or clear the data of other apps like Google Play Services. These actions require Device Owner privileges, which can only be granted via ADB from a computer.

Full ADB commands

# 1. Enable USB debugging on your phone (Developer Options)
# 2. Connect to computer via USB
# 3. Authorize the computer on your phone
# 4. Set this app as device owner:
adb shell dpm set-device-owner com.mdmresetremover.app/.DeviceAdminReceiver

# 5. Verify:
adb shell dpm get-device-owner
⚠️ Important: Setting a device owner requires the device to be factory reset or newly provisioned. If another device owner already exists, you must reset the device first.
